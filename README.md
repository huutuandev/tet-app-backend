Tet App Backend
Backend cho ứng dụng Tết Nguyên Đán, được phát triển bằng Spring Boot với nhiều tính năng hiện đại như AI, Redis Cache, Wallet, Leaderboard và Lucky Draw.
📋 Giới thiệu
Tet App là nền tảng ứng dụng web/mobile phục vụ dịp Tết Nguyên Đán. Phần backend xử lý toàn bộ logic nghiệp vụ, bảo mật, tích hợp trí tuệ nhân tạo và tối ưu hiệu năng.

JWT Authentication
OAuth2 Login (Google, Facebook, ...)
Spring Security

Trí tuệ nhân tạo

Redis Cache
